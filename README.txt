Put the 12 sector tile pictures (PNG) in this folder, using these exact file names:

  Education.png
  Health and Nutrition.png
  Social Welfare and Protection.png
  Transportation.png
  Infrastructure.png
  Environment.png
  Tourism.png
  Food and Agriculture.png
  Labor and Employment.png
  Security, Justice and Peace.png
  Arts, Culture, and Sports.png
  Energy.png

Until a picture is here, that sector shows a simple text tile. As soon as the file exists,
the picture replaces the text tile automatically (no code change). The file names are listed
in data/entries-2025.js (the "art" lines) if you ever want to rename them.
Tip: shrink the pictures first (about 400 pixels wide is plenty) so the page stays fast.
